JARVIS VOICE TIMER — ANDROID CHROME PACKAGE

WHAT THIS IS
- A browser-based app with a JARVIS wake phrase while the page is open and listening.
- Voice commands: “Jarvis, set a timer for 4 minutes”; 5 minutes; 1 hour; “pause timer”; “resume timer”; “stop timer”; “how much time is left?”
- Manual 1-minute, 4-minute, 5-minute, 1-hour and custom timers.
- Installable to your Android home screen once hosted on HTTPS.
- App files are cached for offline reopening; voice recognition may still require internet and browser support.

IMPORTANT LIMITS
- This package is not an APK and is not already hosted online.
- A browser app cannot reliably listen for “Jarvis” after it is closed or when the phone is locked. Keep the app open and tap START LISTENING.
- Timers and alarms may be delayed or silenced if Android suspends Chrome or the app is closed. Do not use this as a critical alarm.
- Web Speech recognition support varies by browser; manual timers still work.

TO USE RIGHT NOW
1. Open index.html in a browser-capable file viewer, then choose Chrome if offered.
2. Manual timers should work even if voice recognition does not. For more reliable voice use, serve the files over HTTPS as described below.

TO INSTALL AS A HOME-SCREEN APP (PHONE-ONLY ROUTE)
1. Sign in to GitHub in Chrome and create a new PUBLIC repository, e.g. jarvis-voice-timer.
2. Extract this ZIP on your phone with your Files app.
3. In the repository, use Add file > Upload files and upload the files from this folder (index.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png). Do not upload only the ZIP.
4. Commit the uploads.
5. Open repository Settings > Pages. Choose Deploy from a branch, choose the main branch and / (root), then Save.
6. When GitHub Pages publishes the site, open the shown HTTPS address in Chrome.
7. Tap INSTALL in JARVIS, or Chrome ⋮ > Install app / Add to Home screen.
8. Open JARVIS from the home-screen icon, allow microphone permission, and tap the round listening button.

Privacy note: GitHub Pages sites are public. Do not upload private files or personal information. Voice recognition on some browsers may send audio to an online recognition service; see browser settings and documentation for details.
